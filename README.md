# dsp

A package for general digital signal processing in haven.

## Installation

Add the following to your `haven.toml`:
```
[dependencies]
dsp = { git = "https://github.com/anselic/dsp" }
```
or
```
dsp = { git = "https://github.com/anselic/dsp", rev = "0a36982" }
```
